  • Skin It to Win It

    A senior capstone skincare recommendation platform that turns user research, quiz logic, and product data into personalized recommendations.

View project website

Abstract: Skin It to Win It is a data-driven skincare recommendation platform designed to simplify how users discover and select products tailored to their skin. The project addresses a common problem in the skincare space: users are often overwhelmed by conflicting information, limited ingredient transparency, and unreliable sources, especially when social media heavily influences purchasing decisions.

The platform combines user research, data modeling, UX/UI design, and interactive web development to translate skincare knowledge into a clear, personalized user experience. A guided quiz evaluates skin dimensions such as oiliness, dryness, sensitivity, and acne-proneness, then maps user responses into a scored skin profile that drives recommendation priorities and product matching.

The project also included a justification survey and infographic to understand purchasing behavior, research habits, confidence levels, and ingredient awareness. Those findings revealed gaps in ingredient knowledge, low confidence in product selection, and reliance on external recommendations, directly informing the platform's feature direction.

A SQL-backed product database was structured to store product and ingredient data, define relationships between ingredients and skin concerns, and support query-based matching between user profiles and products. A high-fidelity Figma prototype mapped the onboarding, quiz, results, and product exploration flows before the functional web app brought the system to life.

The final product is a demonstration-ready full-stack system that connects user research, data modeling, UX design, and application development into one cohesive experience. It moves beyond static analysis by giving users an interactive decision-support tool for making more informed, confident skincare choices.

Role: Web Application Developer and Project Lead. I built the frontend, recommendation logic, database integration, and deployment; defined the project concept and direction; designed and analyzed user research; and structured the system architecture and workflows.
